# Julián J. Galiano Cruz: Portfolio

Personal portfolio site: IT, cybersecurity, project coordination and data analysis.

Static site (plain HTML, no build step), hosted on Cloudflare Pages.

- `index.html`: the page
- `julian.jpg`: profile photo
- `Julian-Galiano-Resume.pdf`: downloadable resume
- `_headers`: Cloudflare security and cache headers
- `robots.txt`: lets search engines index the site
